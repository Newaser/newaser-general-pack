# 三国杀武将扩展包 Wiki

一个用于展示和查阅个人三国杀武将扩展包的 Wiki 网站项目。目标是把扩展包中的武将、技能、游戏牌与规则整理成相互关联、便于浏览的页面，让玩家可以按扩展包或子包查找内容，也能从武将查看技能说明和相关图片。

## 计划提供的内容

- **扩展包与子包**：浏览扩展包介绍、子包划分及其收录内容。
- **武将图鉴**：查看武将编号、称号、势力、体力、技能和武将图片。
- **技能条目**：阅读技能描述、标签、关联图片，以及相关技能、游戏牌和机制。
- **游戏牌与机制**：查阅牌面和规则说明，并沿关联内容继续浏览。
- **图片与署名**：展示武将及其他内容图片，并保留作者或插画师信息。

## 项目现状

目前仓库包含 Wiki 的内容数据和数据结构方案，网站界面与运行入口尚未加入。现有数据收录「☆SPR」与「再谋篇」两个扩展包，共 8 个子包、32 名武将。

## 仓库结构

```text
├── data/
│   ├── packs.json       # 扩展包
│   ├── subpacks.json    # 子包及收录内容
│   ├── generals.json    # 武将
│   ├── skills.json      # 技能
│   ├── cards.json       # 游戏牌
│   ├── rules.json       # 机制
│   └── images.json      # 图片资源元数据
├── image/
│   └── general/         # 武将图片资源
├── data-schema.md       # 数据字段与实体关联约定
└── general-roster.md    # 当前武将清单
```

## 数据约定

资料以 JSON 保存，各文件顶层为数组。实体通过稳定的 `id` 相互关联；图片资源在 `data/images.json` 中登记，路径相对于仓库根目录。字段定义、必填要求和关联示例见[数据结构方案](data-schema.md)。当前武将清单见[武将一览](general-roster.md)。
