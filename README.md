# 三国杀武将扩展包 Wiki

个人三国杀武将扩展包 Wiki 网站，用于浏览扩展包、筛选武将，并查阅单个武将的属性、技能与图片资料。网站从仓库中的 JSON 文件读取内容，方便持续整理和扩充资料。

## 当前内容与功能

目前收录「☆SPR」与「再谋篇」两个扩展包，共 8 个子包、32 名武将。网站包含：

- **扩展包首页**：展示扩展包与子包入口、武将数量和随机武将展示。
- **武将图鉴**：按扩展包、子包和势力筛选，按姓名、编号或称号搜索。
- **武将详情**：查看编号、称号、势力、性别、体力、技能说明及关联牌/规则；有登记图片时也展示卡面、衍生图片和署名。
- **扩展包信息页**：展示相关仓库链接和玩家交流群信息。

## 本地运行

需要安装 Node.js。在项目根目录运行：

```bash
npm start
```

然后打开 <http://localhost:8000>。也可以直接运行 `node server.js`。如需使用其他端口，可设置 `PORT` 环境变量。请通过本地 HTTP 服务器访问网站；直接打开 HTML 文件会受浏览器读取 JSON 的安全限制影响。

```text
├── catalog.html           # 武将图鉴
├── general.html           # 武将详情页
├── about.html             # 扩展包信息页
├── styles.css             # 网站样式
├── script.js              # 首页交互与数据
├── catalog.js             # 图鉴筛选、搜索与列表

```

## 内容数据

JSON 文件顶层均为数组。实体使用稳定的 `id` 相互关联，图片路径相对于项目根目录。新增或修改内容时，请同步维护关联 ID 和 `data/images.json` 中的图片元数据。字段、必填规则与示例参见[数据结构方案](data-schema.md)，武将名单参见[武将一览](general-roster.md)。
