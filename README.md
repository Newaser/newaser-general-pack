# 将册｜三国杀武将扩展包 Wiki

「将册」是个人三国杀武将扩展包 Wiki 网站，用于浏览扩展包与子包、搜索武将，并查阅武将属性、技能、关联规则和图片资料。网站以仓库中的 JSON 文件作为内容数据。

## 当前内容与功能

目前收录「☆SPR」与「再谋篇」两个扩展包，共 8 个子包、32 名武将。网站提供：

- **首页**：展示扩展包和子包入口、武将数量；武将卡面轮播支持上一位/下一位、随机切换、键盘操作和触屏滑动。
- **武将图鉴**：按扩展包、子包和势力筛选，按姓名、编号或称号搜索，并显示武将插画。
- **武将详情**：展示编号、称号、势力、性别、体力、设计者、技能描述及技能关联内容；提供已登记卡面、插画和衍生图片的浏览与署名。
- **关于页面**：介绍扩展包、相关仓库和玩家交流群，并支持复制群号。

## 本地运行

需要安装 Node.js。在项目根目录执行：

```bash
npm start
```

然后访问 <http://localhost:8000>。也可以运行 `node server.js`。默认端口为 `8000`，可通过 `PORT` 环境变量更改。网站通过 `fetch` 读取 JSON，请使用本地 HTTP 服务器访问，不要直接双击 HTML 文件。

## 内容数据维护

各 JSON 文件顶层均为数组。实体通过稳定的 `id` 互相关联；图片文件路径相对于项目根目录，并在 `data/images.json` 中登记。添加或修改资料时，请同步维护相关 ID、图片路径及作者/插画师署名。字段定义、必填规则与关联示例见[数据结构方案](data-schema.md)，当前武将名单见[武将一览](general-roster.md)。
